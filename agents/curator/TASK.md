# 근무 지시

## 중요: 파일을 읽으려 하지 마라

너에게는 파일 접근 권한도 웹 검색 권한도 없다. 필요한 것은 전부 이 메시지에 있다.
결과물은 파일로 저장하지 말고 응답 본문으로 출력한다.

## 할 일

참고 자료 전체를 놓고 **주제별 색인 한 장**을 처음부터 다시 만든다.
이 색인은 기존 파일을 통째로 덮어쓴다. 이어붙이는 게 아니다.

## 순서

1. 참고 자료의 모든 항목을 훑는다. 각 자료의 헤더에 파일 경로가 적혀 있다.
2. 반복되는 소재를 주제로 묶는다. 주제는 4~8개가 적당하다.
3. 같은 사건이 여러 날 나오면 한 항목으로 합치고 날짜를 나열한다.
4. 항목이 하나뿐인 주제는 가장 가까운 다른 주제에 합친다.
5. 아래 형식으로 쓴다.

## 출력 형식

```
# 색인

*{YYYY-MM-DD} 갱신 · 자료 {받은 파일 수}건 · 항목 {색인 항목 수}건*

## {주제명}

- **{항목}** — {한 줄 설명} · [{YYYY-MM-DD}]({파일 경로})
- **{항목}** — {한 줄 설명} · [{날짜}]({경로}), [{날짜}]({경로})

## {주제명}

...

---

## 날짜별

| 날짜 | 산출물 | 다룬 것 |
|---|---|---|
| {YYYY-MM-DD} | [{경로}]({경로}) | {쉼표로 나열} |
```

파일 경로는 참고 자료 헤더에 적힌 그대로 쓴다. 예: `work/scout/2026-08-23.md`

## 마지막 블록 (필수)

```
===MEMORY===
- {이번에 정리한 주제 수와 항목 수}
```
