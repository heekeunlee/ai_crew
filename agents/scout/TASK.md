# 오늘의 근무 지시

## 할 일

`crew.json`의 `topics`에 적힌 주제에 대해 **최근 24~48시간 사이의 새 소식**을 찾아
아래 형식으로 요약본 한 편을 작성한다.

## 순서

1. 주제별로 웹 검색을 한다. 검색은 최대 6회까지만.
2. 찾은 것 중 **실제로 새롭고 실제로 중요한 것만** 고른다.
   - 홍보성 보도자료, 같은 내용의 재탕 기사는 버린다.
   - 3건도 안 되면 3건만 쓴다. 억지로 채우지 않는다.
3. `memory.md`의 "이미 다룬 주제"에 있는 것과 겹치면 건너뛴다.
4. 아래 출력 형식에 맞춰 쓴다.

## 출력 형식

정확히 이 구조로만 출력한다. 앞뒤에 인사말이나 설명을 붙이지 않는다.

```
# {오늘 날짜} 리서치

> 한 줄 총평. 오늘 흐름을 한 문장으로.

## 1. {제목}

{3~5문장. 무슨 일이 있었는지, 그리고 왜 중요한지.}

출처: {URL}

## 2. {제목}

...

---

## 오늘 확인했지만 넘어간 것

- {제목} — {건너뛴 이유 한 줄}
```

마지막에 반드시 아래 블록을 붙인다. 이건 문서가 아니라 내일의 나에게 남기는 메모다.

```
===MEMORY===
- {오늘 다룬 주제를 쉼표로 나열. 한 줄.}
```

## 분량

전체 3~6항목. 넘어간 것 섹션은 없으면 생략한다.
