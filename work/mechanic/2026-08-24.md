## 발견

### README 구조도에 `lib/schedule.mjs`가 빠짐

`scripts/lib/`에는 실제로 `memory.mjs`, `output.mjs`, `sections.mjs`, `state.mjs`, `schedule.mjs` 5개 순수 함수 모듈이 있습니다. `schedule.mjs`는 죽은 코드가 아니라 `scripts/build-state.mjs:13`에서 `import { nextRun } from "./lib/schedule.mjs"`로 실제로 쓰이고, cron 식으로 다음 근무 시각을 계산해 오피스 화면 말풍선("다음 근무까지 남은 시간")에 쓰입니다. 테스트도 `scripts/schedule.test.mjs`로 있고 `package.json:10`의 `test` 스크립트에도 포함돼 있습니다.

그런데 README의 구조도는 `lib/memory.mjs`, `lib/output.mjs`, `lib/sections.mjs`, `lib/state.mjs` 4개만 나열하고 `schedule.mjs`를 빼먹었고, 바로 아래 줄은 테스트 파일을 "4종"이라고 적어놨는데 실제로는 5종입니다. 지난주(2026-08-23) 같은 자리에서 `output.mjs`·`sections.mjs` 누락을 지적해 고쳤는데, 그사이 `schedule.mjs`가 새로 추가되면서 같은 종류의 누락이 다시 생겼습니다.

**위치** `README.md:38-42`
**고치는 법** `lib/state.mjs` 줄 다음에 `lib/schedule.mjs           cron 다음 실행 시각 계산 (순수 함수)` 한 줄을 추가하고, `*.test.mjs  lib/ 모듈별 단위 테스트 4종`을 `5종`으로 고칩니다.
