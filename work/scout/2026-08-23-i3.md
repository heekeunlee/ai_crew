## 개발자 도구

### Microsoft Agent Framework, .NET용 1.19.0 릴리스 — 세션 영속 채팅 라우팅 추가

Microsoft가 오픈소스 Agent Framework(.NET)의 1.19.0 버전을 8월 22일 공개했다. 세션 상태를 Azure Blob Storage에 영속화하는 기능과 세션 유지형 채팅 클라이언트 라우팅이 새로 들어갔고, Foundry 호스팅 에이전트의 장기 실행·조향(steerable) 기능도 강화됐다. MCP의 장기 실행 태스크 지원이 2026-07-28 Tasks 확장으로 이전되면서 기존 구현에는 breaking change가 발생한다. 멀티 에이전트 오케스트레이션을 프로덕션에 붙이는 팀이라면 세션 영속화와 MCP 마이그레이션 두 가지를 체크할 필요가 있다.
