## 개발자 도구

### Cursor Origin 공개 베타 출시

Cursor가 8월 17일 agent-first git hosting 플랫폼 Origin을 공개 베타로 출시했다. 저장소, pull request, 코드 브라우징, 양방향 GitHub 싱크가 에디터 내 새로운 Codebase 탭에서 바로 가능하다. 자동 merge conflict 해결과 Graphite 인수로 확보한 stacked pull request 지원이 특징인데, 성능 클레임은 시간당 29만 6000 클론, 초당 22 commit으로 공격적이다. 이는 SpaceX에 인수된 이후 첫 주요 제품 출시이며, agent scale을 위해 만들었다는 점이 다른 GitHub 클론들과 다르다.

출처: https://siliconangle.com/2026/08/17/cursor-launches-origin-code-hosting-service-to-compete-with-github/

### OpenClaw, GitHub에서 346k 별 돌파

개인용 AI 어시스턴트 OpenClaw가 현재 346k 이상의 별을 모았다. 2025년 말 출시 이후 3개월 만에 React와 Linux kernel을 제친 가장 별 많은 오픈소스 프로젝트 중 하나가 됐다. 로컬 머신에서만 돌아가며 구독료 없이 완전 오픈소스인 점이 광범위한 채택을 이끌었다. 50개 이상 통합(WhatsApp, Slack, Discord 등)을 지원하는 personal gateway로 포지셔닝되어 있다.

출처: https://www.digitalocean.com/resources/articles/what-is-openclaw

JPMorgan이 반도체 회사 Analog Devices에 overweight 평가를 유지했다. 3분기 실적 강세가 데이터센터 성장이 예상을 크게 웃돌 가능성을 시사한다. Alphabet이 자본지출 가이던스를 $195-205B로 상향한 것 이후 광범위한 이익 실현이 진행 중이지만, 이 회사는 강세를 보이고 있다.

## AI 활용 트렌드

### Instagram CEO "진정성이 무한 복제 가능해졌다"

Instagram의 Adam Mosseri가 Threads에 올린 게시물에서 "authenticity is becoming infinitely reproducible"이라 말했다. AI 생성 이미지가 시각적 신뢰를 완전히 무너뜨렸고, 25세 미만 사용자들은 이제 지나치게 깔끔한 사진을 AI로 의심한다. 결과적으로 가장 믿을 만한 콘텐츠는 블러 처리된 candid 사진, 랜덤 DM처럼 "가짜 같지 않은" 것들이 됐다. Meta는 현재 감지되거나 공개된 AI 콘텐츠에 "AI info" 라벨을 적용하고 있으며, Mosseri는 가짜를 찾기보다 진짜에 fingerprint를 하는 것이 더 현실적이라고 제시했다.
