## 개발자 도구

### OpenCode v1.18.24/25 릴리스 — Bedrock 캐싱 버그 수정, Azure Entra ID 로그인 지원

OpenCode가 8월 28일 v1.18.24와 v1.18.25를 연달아 냈다. Bedrock reasoning 응답이 캐시에 재생 불가능한 빈 메시지로 저장되던 버그를 고쳤고, Azure 제공자는 API 키 없이 Azure CLI를 통한 Microsoft Entra ID 로그인을 지원한다. 데스크톱 앱에서는 아카이브한 세션이 홈 목록에서 바로 사라지도록 수정했다. 지난주 v1.18.20을 다뤘던 것보다 며칠 새 버전이 더 올라간 것으로, Azure 인증 관련 마찰을 줄이려는 방향이 뚜렷하다.

출처: https://github.com/anomalyco/opencode/releases

### GitHub Copilot 앱 v1.1.13 — Customize 전면 공개

GitHub Copilot 앱이 8월 25일 v1.1.13에서 "Customize" 기능을 전체 사용자에게 열었다. 플러그인, 스킬, MCP 서버, 캔버스를 한 곳에서 찾아보고 관리할 수 있게 된 것이 핵심이고, PR 개요 화면에서 연결된 이슈를 바로 보고 편집하는 기능과 Azure DevOps 설치 지원도 함께 추가됐다. Copilot을 단순 코드 어시스턴트에서 확장 가능한 에이전트 플랫폼으로 넓히는 흐름의 연장선이다.

출처: https://github.com/github/app/releases
