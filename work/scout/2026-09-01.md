### Claude Code v2.1.252 릴리스

Anthropic이 Claude Code 2.1.252를 배포했다. macOS 일부 환경에서 Bash 명령이 "task output swap refused" 오류로 실패하던 문제, `.claude/settings.local.json`이 없는 프로젝트에서 "always allow" 설정이 저장되지 않던 문제를 고쳤다. claude.ai 연결이 불안정할 때 Remote Control 세션이 수 분간 멈추던 버그와, 디스크가 꽉 찬 상태에서 git 오류처럼 실패 로그가 과도하게 길어질 때 API 요청 크기 제한을 넘기던 문제도 수정했다. 안정성 위주 패치라 눈에 띄는 신기능은 없지만, 최근 며칠간 이어진 세션 안정성 개선 흐름의 연장선이다.

## 미국 증시

### 美-이란 충돌 재점화, 유가 급등에 뉴욕증시 하락

미국이 호르무즈 해협 인근 라라크섬의 이란 미사일 발사대를 타격했고 이란은 UAE 내 미군 기지를 겨냥했다고 주장하면서(UAE는 부인, 자국 영해상 이란 드론 요격만 확인) 한 달 만에 양국 무력 충돌이 재개됐다. 여파로 브렌트유가 3.2% 오른 배럴당 90.91달러까지 뛰었고, S&P500은 0.33% 내린 7,686.14, 나스닥은 0.12% 내린 26,370.89, 다우는 374.09포인트(0.70%) 내린 53,185.90으로 마감했다. 반면 에너지주는 강세여서 엑슨모빌 1.5%, 셰브런 1.4% 올랐다. 8월 한 달 전체로는 상승 마감했지만, 유가 급등이 인플레이션·금리 우려를 다시 자극하는 모양새다.

## 한국 증시

### 코스피, 장중 2%대 급락 후 반도체주 반등으로 상승 마감

8월 31일 코스피는 美-이란 충돌 소식에 개장 직후 175.30포인트(2.58%) 급락한 6,613.58로 출발했지만, 오후 들어 저가 매수세가 유입되며 전 거래일보다 31.14포인트(0.46%) 오른 6,820.02에 마감했다. 삼성전자(+1.17%, 26만원)와 SK하이닉스(+1.27%, 167만4000원)가 반등을 주도했다. 반면 코스닥은 중소형 제약·바이오, 로봇주 낙폭을 끝까지 메우지 못하고 4.12포인트(0.49%) 내린 834.29로 마감해 대형주와 온도차를 보였다. 지정학 리스크가 불거진 날에도 반도체 수급이 지수 방향을 갈랐다는 점을 눈여겨볼 만하다.
