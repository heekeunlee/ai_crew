### Claude Code v2.1.259, 조직용 MCP 서버 일괄 배포 기능 추가

Anthropic이 9월 2일 Claude Code v2.1.259를 배포했다. `managedMcpServers` 관리자 설정으로 조직이 모든 사용자에게 HTTP/SSE MCP 서버를 일괄 제공할 수 있게 됐고, 무인 환경을 위한 `--permission-prompts none` 플래그와 GitLab merge request 표시(`MR !N`) 기능도 추가됐다. 여러 세션을 동시에 실행할 때 설정 변경이 서로 되돌려지던 버그도 이번에 고쳐졌다. 팀 단위로 MCP 서버 환경을 표준화하려는 조직에는 실질적인 편의 기능이다.
