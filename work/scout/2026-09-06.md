## 개발자 도구

### Claude Code v2.1.261 릴리스

Anthropic이 9월 4일 Claude Code v2.1.261을 배포했다. `/status`와 `claude doctor`에 조직 정책 로드 실패 원인을 보여주는 줄이 추가됐고, `bashOutputMaxChars`·`taskOutputMaxChars` 설정으로 명령어·백그라운드 작업 출력을 파일로 빠지기 전 최대 128K자까지 인라인으로 받을 수 있게 됐다. `/skill-doctor`가 새로 생겨 로드된 스킬 중 안 쓰는 것과 그 컨텍스트 비용을 확인할 수 있고, `rm -rf`가 위치 인자에 걸릴 때의 안전 경고도 강화됐다. 매일 반복되는 패치 릴리스지만, 컨텍스트 비용 관리와 세이프가드 강화라는 최근 흐름이 이번에도 이어진다는 점은 눈여겨볼 만하다.
