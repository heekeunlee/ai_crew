## 개발자 도구

### Claude Code v2.1.269 릴리스, plugin eval·output-style 전환 추가

Anthropic이 9월 11일 Claude Code v2.1.269를 배포했다. `claude plugin eval` 명령으로 플러그인의 평가 스위트를 돌려 JSON·HTML 리포트를 받을 수 있게 됐고, `/output-style [name]`으로 Remote Control과 headless 세션에서도 출력 스타일을 바로 전환할 수 있다. Bash 명령이 파일을 수정할 때 diff를 보여주는 `bashEditDiffEnabled` 설정도 새로 생겼다. 보안 쪽에서는 플러그인 압축파일이 world-readable로 풀리던 문제와 재추출 시 이전 파일이 남아있던 버그를 고쳤는데, 세션을 장시간 켜두는 개발자라면 챙겨볼 만하다.

출처: https://code.claude.com/docs/en/changelog

### 코스피, 반도체 대형주 약세로 6,909.91 마감(-1.76%)
