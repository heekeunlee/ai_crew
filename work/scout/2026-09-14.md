# 2026-09-14 리서치

> 미국·한국 증시는 금요일(9/11) 마감 이후 새 마감 데이터가 없는 조용한 월요일 아침, 대신 GitHub에서는 오픈소스 AI 툴 두 건이 트렌딩 1~2위를 다퉜다.

## 개발자 도구

### OpenMontage — 오픈소스 에이전틱 비디오 제작 시스템

calesthio가 공개한 OpenMontage는 "세계 최초의 오픈소스 에이전틱 비디오 제작 시스템"을 표방하며 GitHub 트렌딩 상위에 올랐다. 설명자·애니메이션·아바타·예고편·다큐멘터리 몽타주 등 12개 제작 파이프라인과 비디오·이미지 생성, TTS, 음악, 자막을 아우르는 100개 이상의 프로덕션 도구, 700개 이상의 에이전트 스킬 파일을 묶어 AI 코딩 어시스턴트를 통째로 비디오 제작 스튜디오로 바꾸는 걸 목표로 한다. 라이선스는 AGPLv3다. 코딩 에이전트를 텍스트/코드 생성 도구가 아니라 미디어 프로덕션 파이프라인으로 확장하려는 시도라는 점에서, 에이전트 활용 범위가 어디까지 넓어질 수 있는지 보여주는 사례다.

출처: https://github.com/calesthio/OpenMontage

### colibri — GPU 없이 초대형 MoE 모델 돌리는 순수 C 엔진

JustVugg가 만든 colibri는 GPU 없이도 GLM-5.2/5.3(744B), Kimi K3(2.8T) 등 최대 2.8조 파라미터급 MoE 모델을 소비자용 하드웨어에서 구동하는 엔진이다. 순수 C로 작성돼 별도 의존성이 없고, VRAM·RAM·NVMe를 하나의 계층 구조로 취급해 부족한 메모리 대신 디스크에서 전문가(expert) 모듈을 스트리밍하는 방식으로 동작한다. 최소 25GB RAM에서도 돌아간다고 소개돼 있으며, 현재 v1.11.0까지 나왔고 GitHub 트렌딩에서 3만 star에 가까운 관심을 받고 있다. 로컬 하드웨어로 프론티어급 모델을 돌리려는 수요가 여전히 강하다는 신호다.

출처: https://github.com/JustVugg/colibri
