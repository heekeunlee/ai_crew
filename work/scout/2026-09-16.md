# 2026-09-16 리서치

> 국채금리가 5%대로 재진입하며 미국·한국 증시가 나란히 눌렸지만, 코스닥에서는 AI 보안 테마가 나홀로 상한가 랠리를 벌였다.

## 개발자 도구

### Claude Code 2.1.273, 세션 포킹 기능 추가

Anthropic이 9월 15일 Claude Code 2.1.273을 배포했다. `--remote-control`로 시작한 세션을 포크해 백그라운드에서 별도로 실행할 수 있는 "세션 포킹" 기능이 추가됐고, MCP 서버가 세션 중간에 끊겼다가 재연결에 실패하면 알림을 띄워준다. LLM 게이트웨이로 보내는 요청에 에이전트 타입·컴팩션 여부 등을 담는 헤더도 새로 붙었다. 전날 배포된 2.1.271(클라우드 세션 빠른 모드, /config 패널 마우스 지원)의 후속 버전으로, 원격 세션 운용과 MCP 안정성 쪽 보완이 이어지는 흐름이다.

출처: https://code.claude.com/docs/en/changelog

## 미국 증시

### 10년물 금리 5%대 진입, FOMC 앞두고 3대 지수 동반 하락

9월 15일(현지시간) S&P500은 7,585.73으로 0.45% 내렸고, 나스닥은 25,981.57로 0.78%, 다우존스는 52,093.11로 0.63%(328.09포인트) 하락 마감했다. 이번 주 예정된 연준 금리 결정을 앞두고 10년물 국채금리가 2007년 이후 최고 수준까지 치솟은 게 매도세의 배경이다. 고유가와 맞물린 금리 상승은 성장주·기술주 밸류에이션에 부담을 주는 조합이라 시장이 민감하게 반응했다.

출처: https://finance.yahoo.com/markets/live/stock-market-today-tuesday-september-15-dow-sp-500-nasdaq-081307838.html

## 한국 증시

### 코스피 4거래일 연속 하락, 코스닥은 나홀로 반등

코스피는 9월 15일 6,627.26으로 전일 대비 57.11포인트(0.85%) 밀리며 4거래일 연속 하락했다. 삼성전자·SK하이닉스가 장중 반등했지만 외국인이 현물·선물을 동반 매도하며 지수 상승을 눌렀다. 배경은 미국 10년물 국채금리 5% 돌파와 국제유가 100달러 재진입으로, 미국 증시와 같은 금리·유가 리스크가 그대로 전이된 모습이다. 반면 코스닥은 812.41로 0.70% 오르며 코스피와 디커플링했다.

출처: https://view.asiae.co.kr/article/2026091515343189880

### 코스닥 사이버보안 3종목 동반 상한가

전자서명·인증 전문 아톤(+29.84%, 6,310원), 보안·클라우드 한컴위드(+29.78%), IT서비스 아이티센피엔에스(+29.78%)가 나란히 상한가로 마감했다. 아톤은 장중 4,910원까지 밀렸다가 토큰증권 제도화 기대와 자사 보유 양자내성암호(PQC) 사업이 부각되며 매수세가 몰렸다. AI 에이전트 시대의 인증·접근제어 수요 확대와 젠슨 황의 피지컬 AI 보안 관련 발언이 테마 전반의 수혜 배경으로 꼽힌다. 반도체 대형주가 눌린 날 중소형 보안주가 지수 방향과 무관하게 급등했다는 점이 특이점이다.
