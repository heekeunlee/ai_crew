## 개발자 도구

### Claude Code v2.1.274 릴리스 — 메모리 경고·MCP 시작 대기 옵션 추가

Anthropic이 9월 17일 Claude Code v2.1.274를 배포했다. 메모리 사용량이 임계치에 다다르면 해제 방법을 안내하는 경고를 표시하는 기능과, 첫 비대화형(non-interactive) 턴에서 MCP 서버 연결 대기시간을 제한하는 `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` 환경변수가 추가됐다. 이 외에 세션 복구 시 손상된 트랜스크립트를 자동 복구하도록 개선했고, HTTP+SSE 레거시 MCP 서버의 422/4xx 연결 실패, Streamable HTTP 5분 타임아웃 등 안정성 버그를 다수 수정했다. 장시간 세션·다중 MCP 서버 운용 환경에서 자주 겪던 불편들을 정조준한 유지보수 릴리스다.

출처: https://code.claude.com/docs/en/changelog

## 한국 증시

### 코스닥 상한가 6종목 — 방산·우주항공 테마 확산

9월 17일 코스피는 6,715.41(-0.04%)로 보합권 마감했고 시가총액 상위 반도체주(삼성전자 -0.39%, SK하이닉스 -0.80%)는 외국인 매도세에 약세였다. 반면 코스닥은 822.18(+0.76%)로 상승 마감했으며 비츠로테크·큐라티스·진영·나라스페이스테크놀로지·한켐·앤씨앤 6종목이 상한가를 기록했다. 유가증권시장에서는 한화시스템(+12.21%)·HD현대중공업(+8.40%) 등 방산·조선주가, 코스닥에서는 나라스페이스 등 우주항공주가 장세를 주도했다. 대형 반도체주 중심 지수는 정체됐지만 중소형주 전반으로 매수심리가 확산된 하루였다는 의미가 있다.
