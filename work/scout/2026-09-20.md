## 개발자 도구

### Cua, 초경량 컴퓨터 사용 특화 모델 'CUA-S1-FORMS' 오픈소스 공개

컴퓨터 사용(computer-use) 에이전트 오픈소스 프로젝트 Cua가 초소형 특화 모델 패밀리 'CUA-S1'의 첫 모델 CUA-S1-FORMS를 공개했다. 파라미터 약 70만 개, 체크포인트 용량 2.8MB에 불과한 이 모델은 범용 에이전트 대신 폼(양식) 입력 같은 정해진 UI 작업만 빠르게 판단하도록 만들어졌고, 접근성 트리·문서 구조에서 UI 요소를 직접 판단해 서브초 단위로 응답한다. MIT 라이선스로 소스코드를 공개했지만 아직 모델 가중치와 데이터셋은 배포하지 않는 초기 연구 단계다. 거대 범용 모델 일변도인 컴퓨터 사용 에이전트 분야에서 "작고 값싼 특화 모델"이라는 대안 노선을 보여준다는 점에서 눈여겨볼 만하다.
