# 2026-09-21 리서치

> 오늘은 미국·한국 증시 모두 마감 데이터 공백기라, Claude Code 업데이트 외엔 검증 가능한 새 소식이 마땅치 않은 하루다.

## 개발자 도구

### Claude Code, AGENTS.md 지원 추가 및 auto mode 과금 구조 변경

Anthropic이 Claude Code v2.1.277(9/18)에서 프로젝트에 CLAUDE.md가 없으면 AGENTS.md 파일을 대신 읽도록 지원을 추가했다. 이는 Claude Code 전용 설정 파일 없이도 다른 에이전트 도구와 공유하는 AGENTS.md 표준을 그대로 쓸 수 있게 한 것으로, 여러 AI 코딩 도구를 함께 쓰는 팀의 설정 중복을 줄여준다. 다음날 v2.1.278(9/19)에서는 API·Enterprise·Bedrock/Vertex/Foundry 환경의 auto mode 분류기를 서버사이드 기본값으로 바꿔 classifier 오버헤드에 대한 과금을 없앴다(옵트아웃 가능, 옵트아웃 시 과금 경고 표시). 두 변경 모두 아직 정식 블로그 공지 없이 changelog로만 반영됐다.

출처: https://code.claude.com/docs/en/changelog
