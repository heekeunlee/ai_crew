# 2026-10-06 리서치

> Claude Code 패치 소식 외에는 24~48시간 내 검증 가능한 1차 출처를 찾기 어려웠던 조용한 하루.

## 개발자 도구

### Claude Code v2.1.289 릴리스

Anthropic이 Claude Code를 v2.1.289로 올렸다. 중첩된 셸 명령어 일부에 적용되던 권한 규칙(deny/ask)이 전체 명령어에 제대로 유지되지 않던 문제를 고쳤고, 종료되지 않은 `<script>` 태그가 많을 때 터미널이 멈추는 버그와 심볼릭 링크를 통한 파일 접근 시 Read 거부 규칙이 제대로 걸리지 않던 문제를 수정했다. VSCode 확장에서 `claude auth status` 호출 방식도 고쳐 불필요한 로그아웃 빈도를 줄였다. 보안·안정성 위주의 패치라 화려하진 않지만, 권한 규칙 우회나 터미널 멈춤처럼 실제 사용 중 겪을 수 있는 문제들을 바로 잡은 릴리스다.

## 오늘 확인했지만 넘어간 것

- 미국 증시 (10/5 마감) — 검색 결과마다 수치가 서로 모순됐다(같은 날짜의 다우 종가가 자료마다 다르고, 전일 대비 낙폭 계산도 안 맞음). 신뢰 가능한 1차 출처(거래소·주요 통신사 원문)로 확인하지 못해 제외.
- 한국 증시 (코스피·코스닥, 10/5 마감) — 검색에서 나온 코스피 수치(2,575대)가 최근 수개월간 관찰된 6,500~7,700대 흐름과 전혀 맞지 않았다. 애그리게이터·비공식 사이트 출처뿐이라 신뢰 불가로 제외.
- AI 활용 트렌드 (Threads·X·레딧) — 나노바나나·Sora 2 등 관련 검색에서 최근 24~48시간 내 새로 올라온 구체적 게시물(원문 링크 확인 가능한)을 찾지 못해 제외.
- 오픈소스·프레임워크 신규 릴리스 (Bun/Deno/pnpm/Vite 등) — 검색된 최신 릴리스가 대부분 5~7월 소식으로 오래돼 "신규"가 아니라 제외.
