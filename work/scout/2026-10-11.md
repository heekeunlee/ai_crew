# 2026-10-11 리서치

> 주말이라 증시는 쉬어가고, Claude Code만 조용히 업데이트를 이어갔다.

## 개발자 도구

### Claude Code v2.1.290~294, 기본 Haiku 모델을 5.5로 교체

Anthropic이 지난 며칠 사이 Claude Code를 v2.1.290부터 v2.1.294까지 다섯 차례 업데이트했다. 핵심은 v2.1.293으로, Anthropic API의 기본 Haiku 모델을 1M 컨텍스트를 지원하는 Claude Haiku 5.5로 바꿨다. v2.1.292에서는 `claude plugin install`에 `--marketplace` 소스 지정 옵션과 Agent 툴의 `effort` 파라미터가 추가됐고, PreToolUse 훅 승인이 UNC 네트워크 경로 파일 읽기 요청에서 우회되던 보안 취약점도 같은 버전에서 막혔다. v2.1.294는 프롬프트·에이전트 훅이 지시문만으로 차단해야 할 동작을 허용하던 결함을 수정했다. 새 기능보다는 기본 모델 교체와 훅 보안 패치가 실제 사용에 영향을 주는 변화다.

출처: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
