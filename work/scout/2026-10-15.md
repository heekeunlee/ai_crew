# 2026-10-15 리서치

> JP모건이 외부 AI 에이전트의 고객 계좌 접근을 공식적으로 차단했고, 앤스로픽은 상장을 염두에 둔 첫 실적 공개에 나섰다.

## 개발자 도구

### Claude Code v2.1.299~300 릴리스: 장시간 대화 자동 압축, mod 전용 API 확장

Anthropic이 Claude Code v2.1.299에서 터미널 대화가 길어질 때 자동으로 압축하는 "idle compaction"을 추가했고, 에이전트 뷰에 `/effort`·`/fast` 명령으로 추론 강도를 즉시 조절하는 기능을 넣었다. 뒤이은 v2.1.300에서는 mods(확장 기능)가 서브에이전트의 작업 내역을 메인 화면에 띄우거나 프롬프트창에 안내 텍스트를 얹을 수 있게 하는 API, OpenTelemetry 캐시 수명별 트레이싱 필드 등을 추가했다. 두 버전 모두 로그인·세션·플랜모드 편집 관련 버그 수정이 다수 포함됐다. 코딩 에이전트를 터미널에서 장시간 돌리는 사용자라면 idle compaction과 `/effort` 전환이 체감 차이가 클 변경이다.

## 미국 증시

### JP모건 CEO 다이먼, 외부 AI 에이전트의 고객 계좌 대행 전면 차단

제이미 다이먼 JP모건체이스 CEO가 10/13 3분기 실적 컨퍼런스콜에서 외부 AI 에이전트가 고객을 대신해 계좌 업무를 처리하는 것을 허용하지 않겠다고 밝혔다. 불량 에이전트가 수천 개 생길 수 있어 고객과 은행 모두에 위험이 너무 크다는 이유다. 회사 측은 외부 에이전트에게 잔액조회 등 읽기전용 접근만 허용하고 송금·납부는 막아뒀다고 확인했다. 다만 JP모건은 자사 앱과 내부 업무에는 AI 에이전트를 도입할 계획이라, AI 에이전트 전면 거부가 아니라 "소유권 없는 외부 에이전트"에 대한 선 긋기로 읽힌다.
