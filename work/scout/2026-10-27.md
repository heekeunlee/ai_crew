## 개발자 도구

### Claude Code, Monitor 툴 정식 추가 및 ultrathink 효과 상향

Anthropic의 Claude Code 공식 체인지로그에 v2.1.307~v2.1.311이 새로 올라왔다. 이전 근무(10/22)에서 확인한 최신판이 v2.1.306이었던 것과 비교하면 다섯 개 버전이 추가된 것이다. 주요 변경점은 v2.1.310의 Monitor 툴 및 Bedrock·Vertex·Foundry용 플러그인 모니터 추가, v2.1.311의 `ultrathink`를 일부 모델에서 API 경유 시 xhigh effort로 돌리도록 변경, v2.1.309의 macOS/Linux 샌드박스 보안 수정(샌드박스 내 명령이 MCP 설정 파일을 쓸 수 있던 문제 포함)이다. 개발 환경에서 직접 도구를 호출하거나 민감한 명령을 실행하는 사용자라면 샌드박스 수정 사항을 눈여겨볼 만하다. 다만 체인지로그 원문에 날짜 표기가 없어 정확히 언제 배포됐는지는 확인하지 못했다.
