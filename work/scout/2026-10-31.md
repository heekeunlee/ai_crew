## 개발자 도구

### Claude Code, 작업 디렉터리 밖 쓰기 차단 옵션과 유휴 세션 자동 압축 추가

Claude Code 공식 체인지로그에 v2.1.314가 추가됐다. `permissions.blockWritesOutsideWorkingDirectories` 설정을 켜면 Write·Edit·NotebookEdit 툴이 권한 모드와 상관없이 작업 디렉터리 밖 경로에 쓰는 것을 거부한다. VS Code와 Claude Desktop의 Code 탭에는 유휴 세션 자동 압축(idle compaction)이 추가돼, 20만 토큰이 넘는 대화를 방치하면 자동으로 요약한다. 전자는 에이전트가 의도치 않게 샌드박스 밖 파일을 건드리는 사고를 막는 안전장치고, 후자는 장시간 방치된 대화의 컨텍스트 비대화를 줄여준다.

## 미국 증시

### 아마존·인텔 실적 쇼크에 나스닥 6월 이후 최악의 하루

10월 30일(금) 마감, 나스닥종합지수는 2.86% 내린 25,437.00으로 6월 이후 최악의 하루를 기록했다. S&P500은 1.82% 내린 7,580.07, 다우는 572.25포인트(1.09%) 내린 51,770.31로 마감했다. 아마존은 분기 실적에서 자유현금흐름이 424억 달러 적자를 기록하며 실망감에 하락했고, 인텔은 다음 분기 전망을 약하게 제시하며 장중 한때 29%까지 급락했다. AMD(-11%)·엔비디아(-4%)·브로드컴(-5%) 등 반도체주도 동반 약세였는데, 알파벳·마이크로소프트가 실적발표에서 캐펙스(capex) 전망을 올리지 않은 점이 "AI 투자가 과도했다"는 우려를 다시 키웠다.
