# 2026-11-04 리서치

> 팔란티어가 분기 매출 20억 달러를 처음 넘기며 가이던스를 올렸고, Claude Code는 훅 실패 시 작업을 막는 안전장치를 추가했다.

## 개발자 도구

### Claude Code v2.1.317, 훅 실패 시 작업 차단 옵션 추가

Anthropic이 Claude Code v2.1.317을 공식 체인지로그에 올렸다. Agent SDK 훅 콜백에 `onFailure: "block"` 옵션이 추가되어 콜백이 실패하면 해당 작업을 막을 수 있게 됐다. 웹이나 셸 도구 호출이 계정 이메일 주소를 네트워크로 내보내기 전에 확인을 요청하는 검사도 새로 들어갔다. 바로 전 버전인 v2.1.316(10/31)에서는 Opus 4.8의 fast mode가 11월 30일 제거 예정으로 deprecated됐다는 공지도 있었다. 자동화 훅을 쓰는 사람이라면 실패 시 동작과 PII 전송 여부를 다시 점검할 때다.

출처: https://code.claude.com/docs/en/changelog

## 미국 증시

### 팔란티어, 3분기 매출 23억 달러·사상 첫 상업매출이 정부매출 추월

팔란티어가 11월 2일(현지시간) 장 마감 후 발표한 3분기 실적에서 매출 23억 1,300만 달러(전년 대비 +96%)를 기록했다. 분기 매출이 20억 달러를 넘긴 것도, 미국 상업(commercial) 매출(9억 8,400만 달러, +148%)이 미국 정부 매출(9억 5,300만 달러)을 넘어선 것도 이번이 처음이다. GAAP 희석 EPS는 0.44달러, 조정 자유현금흐름은 12억 1,600만 달러(마진 53%)였다. 회사는 4분기 매출 가이던스를 26억 4,900만~26억 5,300만 달러로, 연간 매출 전망을 85억 3,000만~85억 3,400만 달러로 상향했다 — AI 소프트웨어 수요가 정부 계약 의존도를 넘어 민간 기업으로 확산되고 있다는 신호다.
