# 2026-11-07 리서치

> 미국 중간선거 이후 AI 데이터센터 규제·투자둔화 우려가 반도체주를 이틀째 흔들었다 — 미국은 금요일 반등했지만 한국은 하루 더 급락했다.

## 개발자 도구

### Claude Code v2.1.317~319: MCP 작업 기본 백그라운드 전환, auto mode 거부 정책 강화

Anthropic이 Claude Code 공식 체인지로그에 v2.1.317~319를 올렸다. MCP 도구 작업(tasks)이 이제 기본적으로 즉시 백그라운드로 넘어가고 완료 시 알려주는 방식으로 바뀌었고(`CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND`로 되돌릴 수 있음), auto mode는 텔레메트리나 기능 플래그가 꺼져 있을 때 내장 분류기로 조용히 넘어가는 대신 사용자에게 묻거나 거부하도록 바뀌었다(`permissions.denyInsteadOfPrompting` 신설). IDE 터미널에서 실행할 때 IDE 확장을 자동으로 설치·업데이트하지 않도록 바뀐 점도 눈에 띈다. 자동화 스크립트나 CI에서 Claude Code를 쓰는 개발자라면 MCP 작업이 블로킹되지 않고 넘어가는 동작 변화를 체감할 수 있다.

## 미국 증시

### 금요일 미국 증시, 반도체 '폭락 다음날 사자'로 반등 — 고용지표 서프라이즈도 거들어

11/6(금) 나스닥종합은 1.09% 올라 24,579.42, S&P500은 0.31% 올라 7,376.86로 마감했고 다우는 237.33포인트(0.46%) 내려 51,285.73에 마쳤다. 전날 중간선거에서 민주당이 승리하며 AI 데이터센터 건설·투자가 둔화될 거라는 우려가 터지면서 나스닥이 5.5% 급락(기술적 correction 진입)했는데, 이날 AMD +9%·마이크론 +5%·인텔 +7%·엔비디아 +3% 등 반도체주에 저가 매수가 들어오며 되돌림이 나왔다. 10월 비농업고용이 16.5만 명 증가(예상 5.9만 명)로 서프라이즈를 내며 지수를 지지했지만, 마이크로소프트가 '네오클라우드' 파트너를 줄인다는 보도와 오라클이 MS와의 용량 계약을 축소한다는 블룸버그 보도가 나오며 상승폭을 제한했다. AI 인프라 투자 속도에 대한 시장의 민감도가 그만큼 높아졌다는 뜻이다.

## 한국 증시

### 코스피 6% 폭락 5,059.69, 코스닥도 5%대 급락 — 이틀 연속 반도체주 투매

11/6(금) 코스피는 324.11포인트(-6.02%) 내린 5,059.69로 마감해 올해 3월 31일 이후 최저치를 기록했고, 장중 5,000선이 깨지며 서킷브레이커가 발동됐다. 코스닥도 34.14포인트(-5.03%) 내린 644.27로 작년 4월 이후 최저치였다. 외국인이 코스피에서 약 2조 7,700억 원을 순매도하며 하락을 주도했고, 기관·개인이 받아내며 5,000선을 겨우 지켰다. 전날(11/5) 이미 5.28% 급락했던 데 이은 이틀 연속 급락으로, 미국 중간선거 이후 AI 데이터센터 관련 규제 강화·투자 둔화 우려가 삼성전자·SK하이닉스 등 반도체주로 그대로 옮겨온 결과다.
