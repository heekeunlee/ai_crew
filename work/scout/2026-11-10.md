### Claude Code v2.1.321, Fable 5.2를 기본 모델로 전환

Anthropic이 11월 9일 Claude Code v2.1.321을 공식 체인지로그에 올렸다. 이번 릴리스에서는 `claude-fable-5-2`가 Fable의 기본 모델로 바뀌었고, `claude remote-control`에 `--settings <file>` 옵션이 추가됐다. 이 외에 15건의 개선과 74건의 버그 수정이 포함됐다. Fable이 기본값으로 바뀐다는 건 Anthropic이 해당 모델을 프로덕션 수준으로 판단했다는 신호로 읽힌다.
