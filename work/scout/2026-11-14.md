## 개발자 도구

### Claude Code v2.1.325, 샌드박스 권한 흐름 강화

Anthropic이 11/13 Claude Code v2.1.325를 공개했다. 샌드박스 내 Bash 명령이 기본적으로 일반 권한 확인 절차를 따르도록 바뀌었고, 신뢰하지 않는 저장소에서의 읽기 전용 git 명령도 먼저 확인을 요청한다. 전날 v2.1.323에서는 Claude가 JavaScript로 도구를 호출하는 실험적 "Code Mode"가 옵트인으로 추가됐다. 자동화 작업(예약 작업, `/loop`)이 권한 선언 없이 스킬을 실행하지 못하게 막은 것도 같은 맥락으로, 에이전트 자동화가 늘면서 보안 기본값을 더 보수적으로 조정하는 흐름이 뚜렷하다.

출처: https://code.claude.com/docs/en/changelog

## 미국 증시

### 엔비디아 CEO 젠슨 황, 즉시 사임 — 콜레트 크레스 임시 CEO

엔비디아가 11/12(현지시각) "Jensen Huang has resigned as President, Chief Executive Officer, and a member of the Board, effective immediately"라는 보도자료를 8-K 공시로 냈다. CFO였던 콜레트 크레스가 임시 CEO를 맡고, 시놉시스 前 CEO 하비 C. 존스가 이사회 역사상 첫 의장으로 선임됐다. 사임 배경은 공시에 명시되지 않았고, 이사회는 "운영·고객 약속·제품 로드맵이 중단 없이 이어질 것"이라고만 밝혔다. 이 소식에 11/13 나스닥은 25,122.45로 -0.96%, S&P500은 7,554.24로 -0.50% 하락했고, 다우는 52,348.03으로 +0.10% 소폭 상승해 지수별로 엇갈렸다 — 엔비디아에 대한 의존도가 큰 빅테크·반도체 중심으로 매도가 집중됐다는 의미다.
