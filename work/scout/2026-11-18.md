## 개발자 도구

### Claude Code v2.1.326: 샌드박스 쓰기 범위 축소 + 로그인 파일 보호

Anthropic이 11월 16일 Claude Code v2.1.326을 공식 배포했다. macOS·Linux·WSL에서 샌드박스로 실행되는 명령이 일부 민감한 홈 폴더에 기본적으로 쓰지 못하도록 바뀌었고, 필요하면 `sandbox.filesystem.allowWrite` 설정으로 허용해야 한다. 또 파일 도구가 `.credentials.json` 같은 Claude Code 로그인 파일에 대한 쓰기 요청을 거부하도록 변경됐고, Code Mode를 agent teams와 함께 켤 수 있게 됐다. 에이전트가 파일시스템에 광범위하게 접근하는 구조상 샌드박스 격리와 인증정보 보호는 사소해 보여도 실제 사고를 막는 쪽에 가까운 업데이트다.

출처: https://code.claude.com/docs/en/changelog

## 미국 증시

### 다우 1.64%·S&P 1.03% 하락, NSA 네트워크 장애설에 엔비디아 리더십 불안 겹쳐

11월 17일(화) 다우존스는 848.75포인트(-1.64%) 내린 50,759.42, S&P500은 7,340.53(-1.03%, 7월 말 이후 최저 종가), 나스닥은 24,328.38(-0.74%)로 마감했다. CNBC에 따르면 장중 CNN이 미 국가안보국(NSA) 기밀 네트워크 장애를 보도하며 다우가 한때 1,000포인트 넘게 빠지는 등 충격이 커졌으나(NSA는 "정기 점검 중 일시 저하"라며 사이버공격 증거는 없다고 해명), 이와 별개로 젠슨 황 전 CEO 사임 이후 이어진 AI·반도체주 불안과 엔비디아 실적 발표를 앞둔 경계감이 하락을 뒷받침했다. 엔비디아는 0.5% 내렸고 코어위브·네비우스 등 네오클라우드 종목이 더 크게 밀렸다. 전일(11/16, 다우 -1.41%·S&P -1.92%·나스닥 -2.49%)에 이어 사흘 연속 하락으로, CEO 교체 쇼크에서 시장이 아직 벗어나지 못했다는 신호다.

출처: https://www.cnbc.com/2026/11/16/stock-market-today-live-updates.html (본문은 11/17 마감 기준, URL 슬러그만 11/16)

## 한국 증시

### 코스피 2.59%·코스닥 2.34% 추가 하락, 美 AI주 셀오프 연동 추정

11월 17일 코스피는 4,968.48로 전일 대비 2.59% 내렸고, 코스닥은 650.06으로 2.34% 하락했다. 전일(11/16)에도 코스피 -3.59%·코스닥 -4.86%로 급락해 이틀 연속 큰 폭의 하락이다. 같은 날 미국 증시도 엔비디아 리더십 불안과 AI·반도체주 약세로 동반 하락한 만큼 국내 증시도 같은 흐름에 연동됐을 가능성이 높지만, 이를 명시적으로 짚은 국내 1차 기사는 이번에도 찾지 못했다(검색 인덱싱 지연으로 추정). 반도체 대형주 비중이 큰 코스피·코스닥이 美 AI 밸류에이션 우려에 그대로 노출돼 있다는 점을 보여준다.
