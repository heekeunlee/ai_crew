# 2026-11-19 리서치

## 개발자 도구

### Claude Code v2.1.327 공개

Anthropic이 11/17 Claude Code v2.1.327을 공식 체인지로그에 올렸다. `ExitWorktree`가 미저장 작업이 남은 워크트리를 지울 때 확인을 거치도록 바뀌었고, `claude mcp add/remove`가 `.mcp.json`의 다른 최상위 키(예: `$schema`)를 삭제하던 버그가 수정됐다. `permissions.blockReadsOutsideWorkingDirectories`가 더 많은 Bash 명령을 차단·확인 대상으로 잡도록 강화됐고, VS Code에는 탐색기에서 파일을 바로 채팅에 멘션하는 "Add to Chat" 메뉴가 추가됐다. 이번 릴리스는 기능 추가보다 권한·샌드박스 관련 수정과 100건의 버그 픽스가 중심이라, 보안 설정을 세밀하게 쓰는 팀일수록 체크할 만하다.

출처: https://code.claude.com/docs/en/changelog

## 미국 증시

### 엔비디아 3분기 매출 1,158억달러로 깜짝 증가, 美 지수는 엇갈려 마감

엔비디아가 11/17(현지시간) 장 마감 후 공시한 2027 회계연도 3분기(10/25 종료) 실적에서 매출 1,158억4,400만달러(전년동기대비 103%, 직전분기대비 20% 증가), GAAP 영업이익 775억2,000만달러, 순이익 652억8,700만달러, 희석 EPS 2.70달러를 기록했다. 4분기 매출 가이던스도 1,300억달러(±3%)로 추가 성장을 예고했는데, 중국向 데이터센터 매출은 전망에 반영하지 않았다고 명시했다. 이 실적 발표 영향으로 11/18(수) 나스닥은 기술주 강세에 힘입어 +0.42%(24,429.88)로 올랐지만, 다우(-1.11%, 50,197.78)와 S&P500(-0.23%, 7,323.52)은 다른 우려(연준 금리 경계감 등)로 떨어지며 지수별로 엇갈린 마감을 보였다. 같은 기간 진행 중인 앤트로픽 IPO 기대도 투자자들의 관심사로 거론됐다.

출처: NVIDIA 2027 회계연도 3분기 실적(SEC 8-K) https://www.sec.gov/Archives/edgar/data/0001045810/000104581026000088/q3fy27pr.htm · 지수 수치 https://www.investing.com/indices/us-30-historical-data (2차)

## 한국 증시

### 코스피·코스닥, 이틀 연속 급락분 상당 부분 반납

코스피는 11/18(수) 전일(4,968.48, -2.59%) 대비 1.99% 오른 5,067.44로, 코스닥은 1.96% 오른 662.81로 마감해 이틀 연속 급락의 상당 부분을 되돌렸다. 반등 시점이 엔비디아의 분기 매출 급증 발표(11/17 美 현지시간 장마감 후) 직후라는 점에서 반도체 투자심리 회복이 영향을 준 것으로 보이지만, 이를 명시적으로 연결한 국내 1차 출처 기사는 찾지 못해 추정으로만 적는다. 업종별·수급 주체별 구체적인 매수 내역도 이번엔 확인하지 못했다.
