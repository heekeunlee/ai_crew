# 2026-11-21 리서치

> 간밤 미국 3대 지수가 나란히 "correction"(고점 대비 10%↓) 영역에 진입하며 AI 밸류에이션 우려가 코스피·코스닥 급락으로 그대로 옮겨붙었다.

## 개발자 도구

### Claude Code v2.1.329 공개 — `/code-review` 기본 동작 변경, Code Mode에 OpenTelemetry 지원 추가

Anthropic이 11/19(현지시간) Claude Code v2.1.329를 릴리스했다. 대부분 모델에서 타깃 없이 `/code-review`를 실행하면 기본 브랜치 전체 diff를 검토하도록 바뀌었고, 멀티커밋 브랜치에서 diff가 사라지는 버그도 고쳤다. Code Mode가 OpenTelemetry 이벤트·메트릭이 켜진 상태에서도 동작하도록 확장됐고, 폴더의 훅이 어디서 선언됐는지 보여주는 신뢰 다이얼로그 경고, 매니지드 설정의 훅 로드 실패 알림 등도 추가됐다. 코드 리뷰 워크플로를 자동화에 많이 의존하는 개발자라면 기본 동작 변경을 눈여겨볼 필요가 있다.

출처: https://code.claude.com/docs/en/changelog.md

## 미국 증시

### S&P500·다우 "correction" 진입, 나스닥은 올해 상승분 반납 — AI 랠리 되돌림 가속

11/20(금) 뉴욕 증시에서 다우는 48,147.33(-1.93%), S&P500은 6,910.39(-3.7%), 나스닥은 22,617.73(-5.28%)로 마감했다. CNBC는 이로써 S&P500과 다우가 고점 대비 10% 하락한 "correction" 영역에 들어갔고 나스닥은 올해 상승분을 모두 지웠다고 보도했다. Anthropic IPO 이후 기대와 달리 차익매물이 쏟아져 Anthropic 주가가 8.5% 빠졌고, 엔비디아(-14%, 로이터의 SEC 회계 이슈 검토 보도 영향)·AMD(-13%)·마이크론(-14%) 등 AI·반도체 대형주가 동반 급락했다. 주간 기준으로 다우 -8%(2020년 3월來 최악), S&P500 -8.6%(2025년 4월來 최악)를 기록하며 AI 캐펙스 둔화 우려와 12월 FOMC 금리 불확실성이 겹친 한 주였다.

출처: https://www.cnbc.com/2026/11/19/stock-market-today-live-updates.html

## 한국 증시

### 코스피·코스닥 동반 5%대 급락 — 美 AI 셀오프 직격

11/20(금) 코스피는 4,869.96(-5.21%), 코스닥은 645.68(-5.71%)로 마감했다. 전일(11/19) 각각 +1.39%, +3.32%로 반등했던 흐름이 하루 만에 꺾인 것으로, 같은 날 미국 증시가 엔비디아·AMD·마이크론 등 AI·반도체 대형주 급락 속에 correction에 진입한 것과 시점이 맞물린다. 국내 급락 원인을 직접 짚은 1차 기사는 아직 찾지 못했지만, 간밤 미국발 AI 밸류에이션 우려가 국내 반도체주로 전이됐을 가능성이 높다. 다만 이 연결 관계는 추정이며 국내 1차 소스로 확정하지는 못했다.
