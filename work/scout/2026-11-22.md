## 개발자 도구

### Claude Code v2.1.330: 엔터프라이즈 로그인 확장, rm 명령 보호, /loop 최대 실행기간 4배 연장

Anthropic이 11월 20일 Claude Code v2.1.330을 배포했다. Enterprise Admin Console로 관리되는 조직 로그인을 지원하고, 반복 예약 작업과 `/loop`의 최대 실행 기간을 7일에서 30일로 늘렸다. 루트·홈·작업 폴더를 겨냥한 `rm` 명령은 이제 승인을 요구하며 승인자가 없으면 거부되도록 바뀌었는데, 이는 에이전트가 무심코 상위 폴더를 지우는 사고를 막기 위한 조치다. 그 외 긴 대화를 compact한 뒤 수 분간 멈추는 문제, WebFetch가 일부 페이지에서 빈 결과를 반환하는 문제 등 98건의 버그를 수정했다.
