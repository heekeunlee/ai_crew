# 2026-11-26 리서치

## 개발자 도구

### Claude Code v2.1.332, MCP 서버 스킬 연동 추가

Anthropic이 11/25 Claude Code v2.1.332를 공개했다. MCP 서버가 제공하는 스킬을 `/` 메뉴에 `server:skill` 형식으로 노출하는 기능(베타)을 추가했고, 스킬·커맨드 로드 시 inline shell 명령을 가로채 거부할 수 있는 `PreSkillShellCommand` 훅 이벤트를 신설했다. 구글 클라우드 Agent Platform과 마이크로소프트 Foundry의 `sonnet`/`opus` 모델 별칭을 각각 Sonnet 5.5·Opus 5.5로 올리는 등 모델 라우팅 기본값도 다수 바뀌었고, 버그 수정 93건·개선 19건이 함께 담겼다. 매일 기능이 쌓이는 도구지만 이번엔 "MCP 스킬 통합"처럼 에이전트 생태계를 넓히는 방향이 눈에 띈다.

## 미국 증시

### AI주 이틀째 조정, 관세·물가 우려에도 장중 저점서 반등

11/25(수) 마감 다우 50,182.95(+0.3%)·S&P500 7,182.78(-0.3%)·나스닥 23,585.80(-0.6%)로 지수별로 엇갈렸다. S&P500은 장중 한때 3.2%까지 밀렸다가 낙폭 대부분을 되돌렸는데, 11/23 젠슨 황 엔비디아 CEO 복귀 랠리 이후 이틀째 이어지는 AI 관련주 조정과 고물가 지표, 트럼프 대통령의 대중(對中) 무역전쟁 확대 가능성이 배경으로 지목됐다. 국채 수익률은 하락했다. 나흘 전 복귀 소식에 폭등했던 AI 랠리 열기가 이틀 만에 식어가는 흐름이 계속되고 있다는 뜻이다.

## 한국 증시

### 코스피 6.16% 급락, 美 반도체 삭풍에 매도 사이드카 발동

11/25(수) 코스피는 전 거래일보다 308.52포인트(6.16%) 내린 4,697.51에 마감했고 코스닥도 2.29% 떨어졌다. 개장 직후에는 프로그램 매도호가 효력이 5분간 정지되는 매도 사이드카가 발동됐다. 필라델피아 반도체지수가 7.88% 급락하고 엔비디아(-5.9%)·마이크론(-11%)·샌디스크(-11.1%)가 동반 급락한 영향이 국내 반도체 대형주로 번졌고, 여기에 USTR이 한국·중국·EU 등 16개 경제권에 신규 관세를 발표할 것이라는 보도와 12월 Fed·한은 금통위 금리 인상 경계감이 겹쳤다. 외국인이 유가증권시장에서 1조8,994억원을 순매도하며 하락을 주도했다. 전날(11/24) 황 CEO 복귀 랠리로 코스피가 5,000선을 회복했던 만큼, 하루 만에 그 열기가 꺼진 셀이 반전이라는 점이 눈에 띈다.
